# VibeCoding — Codex 项目集合

本仓库用于集中管理通过 OpenAI Codex 辅助开发的小型工具、自动化脚本与实验性项目。

每个项目使用独立文件夹，方便后续维护、迭代和备份。

## 项目目录

| 项目 | 说明 |
|---|---|
| `chaoxing_homework_reminder/` | 超星学习通作业提醒工具 |
| `codex_quota_manager/` | Codex 额度管理工具 |
| `codex_status_light/` | Codex 状态指示工具 |

## 项目分类规则

**适合存放：**
- Codex 开发的实用小工具
- 自动化脚本与效率工具
- 临时实验和功能验证项目
- 不需要独立发布的小型程序

**不适合存放：**
- 需要长期维护的正式网站或 App
- 与现有项目无关的大型工程
- 私人密钥、Token、密码及敏感数据

正式产品应尽量迁移至独立 GitHub 仓库。

## Git 版本管理规范

1. 每个项目独立使用一个顶层文件夹。
2. 修改代码前确认项目路径，避免影响其他项目。
3. `main` 分支保存经过基本检查的版本。
4. 大型修改优先使用独立开发分支。
5. 提交时使用清晰的 Commit message。
6. 未经确认不得执行强制推送、批量删除或覆盖其他项目文件。
7. 项目停止维护后保留已有源码，并说明维护状态。

## 开发与维护

- 开发工具：Visual Studio Code、Codex、Git
- 代码托管：GitHub
- 使用方式：各项目分别查看自己的源码及运行说明
- 更新方式：本地开发、测试后通过 Git 提交和推送

## 说明

本仓库为个人开发与学习项目集合，各工具的完成程度和维护状态可能不同。

项目代码应根据实际使用环境进行必要验证。
